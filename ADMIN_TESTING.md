# 🚀 Инструкция по тестированию Telegram админки

## 1️⃣ Получить свой Telegram ID

**Вариант А (через бота):**
1. Откройте Telegram
2. Найдите бота `@userinfobot`
3. Напишите ему `/start`
4. Бот отправит вам ваш ID (что-то вроде: `123456789`)

**Вариант Б (через админ бота):**
1. Откройте бота `aaaaa_admin_bot` (который вы создали)
2. Напишите ему любое сообщение
3. Откройте консоль разработчика проекта и ищите в логах ID отправителя

## 2️⃣ Обновить .env файл

Откройте `.env` и замените:
```
ADMIN_TELEGRAM_ID="ТУТ_ЗАМЕНИ_НА_СВОЙ_ID"
```

На ваш ID, например:
```
ADMIN_TELEGRAM_ID="123456789"
```

## 3️⃣ Запустить проект

```bash
npm run dev
```

Проект запустится на `http://localhost:3000`

## 4️⃣ Тестирование

### Шаг 1: Откройте админку
Перейдите на: `http://localhost:3000/admin`

### Шаг 2: Введите учетные данные
- **Email:** `admin@example.com`
- **Пароль:** `admin123`

Нажмите кнопку "Получить код"

### Шаг 3: Проверьте Telegram
Вы должны получить сообщение в Telegram вида:
```
🔐 Код входа в админку: 123456

Код действителен 5 минут.
```

### Шаг 4: Введите код
Скопируйте код из Telegram сообщения и введите его в форму на странице.

### Шаг 5: Успех! ✓
После ввода верного кода вы будете перенаправлены на `/admin/dashboard`

|---|---|---|

## 🧪 Возможные проблемы и решения

### Проблема: "Telegram не настроен"
**Решение:** Проверьте, что в `.env` правильно заполнены:
- `TELEGRAM_BOT_TOKEN`
- `ADMIN_TELEGRAM_ID` (самое важное!)

### Проблема: Код не приходит в Telegram
**Решение:**
1. Проверьте ID в `.env` (выполните шаги 1-2 выше)
2. Убедитесь, что вы написали боту `/start` хотя бы один раз
3. Посмотрите логи в консоли проекта (ошибка должна быть там)

### Проблема: "Неверный email или пароль"
**Решение:** Используйте точные данные из `.env`:
- Email: `admin@example.com`
- Пароль: `admin123`

### Проблема: Форма не отправляется
**Решение:** 
1. Откройте Developer Tools (F12)
2. Перейдите на вкладку Console
3. Посмотрите ошибки
4. Проверьте, запущен ли dev сервер (`npm run dev`)
