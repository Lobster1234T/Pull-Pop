## 🎯 Что это такое?

Это **полнофункциональная система аутентификации** для приложения AVATAR с поддержкой:

✅ **Email/Пароль** - Регистрация и вход  
✅ **Google OAuth 2.0** - Вход через Google  
✅ **JWT токены** - Безопасные сессии (7 дней)  
✅ **Хеширование паролей** - bcryptjs (10 salt rounds)  
✅ **Валидация** - На клиенте и сервере  
✅ **Мобильный дизайн** - Полная адаптивность  
✅ **Профиль пользователя** - Меню в Header

## 🛠️ Технические детали

### Используемые пакеты
- **bcryptjs** - Хеширование паролей
- **jsonwebtoken** - JWT токены
- **jose** - Верификация JWT
- **Prisma** - ORM база данных

### Переменные окружения
```env
# Google OAuth
NEXT_PUBLIC_GOOGLE_CLIENT_ID=207923757415-hdvrupobie15fhrvientugvtrnu1vr5i.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your-google-client-secret

# JWT
JWT_SECRET=your-jwt-secret

# App
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

### Модели БД
- **User** - Основной пользователь
- **UserProfile** - Профиль (имя, фото, язык)
- **UserSession** - Активные сессии
- **Customer** - Расширенная информация

## 🔐 Безопасность

✅ **Пароли**
- Хешируются перед сохранением
- Никогда не отправляются в открытом виде
- Минимум 6 символов

✅ **Токены**
- Подписаны с JWT SECRET
- Срок действия 7 дней
- Хранятся в localStorage и БД

✅ **Сессии**
- Отслеживание IP
- User-Agent проверка
- Проверка статуса пользователя

✅ **Валидация**
- Email формат проверяется
- Все поля обязательны
- Дублирование email предотвращено

## ❓ FAQ

**Q: Где хранится токен?**  
A: В localStorage браузера и в БД в таблице UserSession

**Q: Как долго действует токен?**  
A: 7 дней (можно изменить в коде)

**Q: Google OAuth работает локально?**  
A: Да, ключи настроены для localhost:3000

**Q: Можно ли менять дизайн?**  
A: Да, все стили в Tailwind CSS классах

**Q: Можно ли добавить другие методы входа?**  
A: Да, используй тот же паттерн что и Google OAuth
