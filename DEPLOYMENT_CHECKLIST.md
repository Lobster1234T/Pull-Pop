## Частые проблемы и решения

### Ошибка: "Build failed"

**Решение:**
1. Проверить логи: Vercel Dashboard → Deployments → Build logs
2. Убедиться, что все зависимости установлены
3. Проверить синтаксис TypeScript
4. Убедиться, что env переменные установлены

### Ошибка: "Database connection failed"

**Решение:**
1. Проверить DATABASE_URL в Vercel env
2. Убедиться, что БД доступна (IP whitelist)
3. Выполнить: `npx prisma migrate deploy`
4. Проверить логи Prisma

### Ошибка: "JWT_SECRET is not defined"

**Решение:**
1. Добавить JWT_SECRET в Vercel env
2. Перередеплоить: Vercel Dashboard → Deployments → Redeploy

### Ошибка: "Cloudinary upload failed"

**Решение:**
1. Проверить CLOUDINARY_CLOUD_NAME
2. Проверить CLOUDINARY_UPLOAD_PRESET
3. Убедиться, что preset позволяет загрузки

### Медленные запросы

**Решение:**
1. Добавить индексы в Prisma миграции
2. Использовать connection pooling (PgBouncer)
3. Оптимизировать N+1 запросы
4. Включить кеширование ответов
