## 💡 Как использовать?

### Для конечного пользователя
1. Нажать **"Вход"** в Header
2. Выбрать **"Регистрация"** или **"Вход"**
3. Заполнить форму
4. Нажать **"Создать аккаунт"** или **"Войти"**
5. **ИЛИ** нажать **"Войти через Google"**

✅ Готово! Вы залогинены!

### Для разработчика

```typescript
// Получить текущего пользователя
import { getCurrentUser } from '@/app/utils/auth';
const user = getCurrentUser();

// Проверить авторизацию
import { isLoggedIn } from '@/app/utils/auth';
if (isLoggedIn()) {
  // Защищенный код
}

// Выход
import { clearAuth } from '@/app/utils/auth';
clearAuth();
```
