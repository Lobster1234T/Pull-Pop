## 🎯 Что нужно сделать ЛЬ:

### 1. Получить ваш Telegram ID
1. Откройте Telegram
2. Найдите бота `@userinfobot`
3. Напишите `/start`
4. Скопируйте ваш ID

### 2. Обновить .env
Откройте `c:\Users\Odyssey\Desktop\avatar\avatar\.env` и замените:
```
ADMIN_TELEGRAM_ID="ТУТ_ЗАМЕНИ_НА_СВОЙ_ID"
```
На ваш ID, например:
```
ADMIN_TELEGRAM_ID="123456789"
```

### 3. Запустить dev сервер
```bash
npm run dev
```

### 4. Открыть админку
```
http://localhost:3000/admin
```

### 5. Тестировать
- Email: `admin@example.com`
- Пароль: `admin123`
- Получить код → Проверить Telegram → Ввести код → Вход ✓

## 📝 Примечания

### Текущая функциональность:
1. **Форма входа** - вводим email и пароль
2. **Отправка кода** - 6-значный код в Telegram
3. **Проверка кода** - защита от 3 неверных попыток
4. **Сессия** - cookie на 24 часа
5. **Выход** - кнопка выхода на странице dashboard

### Хранилище кодов:
- Текущее: **оперативная память** (теряется при перезагрузке)
- Для продакшена: **БД (Prisma)**

### Безопасность:
- Текущее: базовая
- Нужно добавить: bcrypt, логирование, rate limiting, HTTPS
