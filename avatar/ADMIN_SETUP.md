# Настройка Telegram админки

## Что создано:

### 1. API маршруты:
- `/api/admin/send-code` - отправляет 6-значный код в Telegram
- `/api/admin/verify-code` - проверяет введенный код

### 2. Страницы:
- `/admin` - форма входа (email + пароль)
- `/admin/dashboard` - защищенная страница админки

### 3. Процесс входа:
1. Пользователь вводит email и пароль на странице `/admin`
2. При верных данных сервер отправляет 6-значный код в Telegram бот
3. Пользователь вводит полученный код
4. После проверки кода устанавливается cookie сессии и редирект в `/admin/dashboard`

## Необходимая настройка .env:

```
DATABASE_URL="..."
TELEGRAM_BOT_TOKEN="YOUR_TELEGRAM_BOT_TOKEN"
ADMIN_EMAIL="admin@example.com"
ADMIN_PASSWORD="admin123"
ADMIN_TELEGRAM_ID="1234567890"  ← ВАЖНО: замените на ID вашего чата в Telegram
NODE_ENV="development"
```

## Как получить ADMIN_TELEGRAM_ID:

1. Напишите боту: `/start`
2. Бот ответит с вашим ID (или используйте бота @userinfobot)
3. Скопируйте ID в переменную `ADMIN_TELEGRAM_ID`

## Установка зависимостей:

```bash
npm install
```

Добавлена зависимость `node-telegram-bot-api` в package.json

## Запуск проекта:

```bash
npm run dev
```

Откройте `http://localhost:3000/admin`

## Тестирование:

1. Введите email: `admin@example.com`
2. Введите пароль: `admin123`
3. Нажмите "Получить код"
4. Проверьте Telegram - там должно прийти сообщение с кодом
5. Введите код в форме
6. При верном коде перенаправит на `/admin/dashboard`

## Особенности текущей реализации:

⚠️ **ВАЖНО для продакшена:**
- Коды хранятся в памяти (теряются при перезагрузке сервера)
- Нужно хранить коды в БД с сроком действия
- Пароли должны быть захеширован (bcrypt)
- Нужна обработка хака брутфорса
- Cookie нужны дополнительные проверки безопасности
