- ✅ Пароли хешируются перед сохранением

- ✅ Дублирование email предотвращено

## 🚀 Как начать работу

### 1. Установить зависимости
```bash
npm install
```

### 2. Обновить .env
Убедитесь что все переменные установлены (уже добавлены)

### 3. Запустить dev сервер
```bash
npm run dev
```

### 4. Открыть в браузере
```
http://localhost:3000
```
