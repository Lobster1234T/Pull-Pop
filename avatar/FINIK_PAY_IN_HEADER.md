## 🚀 Использование

### Для пользователя

1. Авторизуется на сайте
2. Видит кнопку "Оплатить" в header (desktop) или мобильное меню (mobile)
3. Нажимает кнопку
4. Открывается модальное окно с информацией о платеже
5. Нажимает кнопку "Оплатить 5 сомов" внутри окна
6. Редиректится на платежную страницу Finik
7. Сканирует QR-код своей карточкой Finik
8. Платеж проходит

### Для разработчика

```tsx
// Кнопка автоматически управляется state:
const [isFinikModalOpen, setIsFinikModalOpen] = useState(false);

// При клике на кнопку открывается модальное окно:
onClick={() => setIsFinikModalOpen(true)}

// Модальное окно вызывает компонент:
<FinikPaymentModal 
  isOpen={isFinikModalOpen} 
  onClose={() => setIsFinikModalOpen(false)} 
  userId={user.id}
/>
```

## 🧪 Тестирование

### 1. Запустите приложение

```bash
npm run dev
```

### 2. Авторизуйтесь

- Откройте http://localhost:3000
- Нажмите "Регистрация" или "Вход"
- Авторизуйтесь

### 3. Посмотрите Header

- На **desktop**: Справа от языка видна зелёная кнопка "Оплатить"
- На **mobile**: Раскройте меню (☰) и видите кнопку "Оплатить 5 сомов"

### 4. Нажмите кнопку

- Откроется красивое модальное окно платежа
- Там информация о платеже (5 сомов, Finik Pay, KGS)
- Кнопка "Оплатить 5 сомов" внутри окна
- Кнопка "Отмена" для закрытия

### 5. Нажмите "Оплатить"

- Редиректитесь на платежную страницу Finik
- Или видите ошибку (в зависимости от настроек)

## 🎯 Последовательность действий

```
1. Пользователь авторизуется
   ↓
2. Header отображает кнопку "Оплатить"
   ↓
3. Пользователь нажимает кнопку
   ↓
4. Открывается FinikPaymentModal
   ↓
5. Пользователь нажимает "Оплатить 5 сомов"
   ↓
6. Открывается PaymentButton компонент
   ↓
7. Отправляется запрос на /api/finik/create-payment
   ↓
8. Получается paymentUrl
   ↓
9. Редиректится на Finik
   ↓
10. Пользователь платит (сканирует QR-код)
   ↓
11. Finik отправляет webhook
   ↓
12. Статус платежа обновляется в БД
   ↓
13. Пользователь видит успех!
```
