# Система локализации (i18n) - Краткое руководство

## Что было добавлено

Полная система локализации (internationalization) для поддержки трёх языков:
- 🇷🇺 Русский (ru)
- 🇬🇧 English (en)
- 🇰🇬 Кыргызча (kg)

## Структура папок

```
app/
└── i18n/
    ├── locales/
    │   ├── ru/main.json      (Русские переводы)
    │   ├── en/main.json      (Английские переводы)
    │   └── kg/main.json      (Кыргызские переводы)
    ├── config.ts             (Конфигурация)
    ├── translations.ts       (Ядро i18n)
    ├── useLanguage.ts        (React хук)
    ├── LanguageSwitcher.tsx  (Компонент кнопок)
    ├── index.ts              (Экспорты)
    └── README.md             (Полная документация)
```

## Быстрый старт

### 1. Используйте переводы в компонентах

```tsx
'use client';

import { useLanguage } from '@/app/i18n';

export default function Home() {
  const { t } = useLanguage();

  return (
    <h1>{t('hero.title')}</h1>
  );
}
```

### 2. Добавьте переключатель языков

```tsx
import { LanguageSwitcher } from '@/app/i18n';

// В вашей навигации или меню
<LanguageSwitcher />
```

### 3. Добавьте новые переводы

1. Отредактируйте файлы `app/i18n/locales/{lang}/main.json`
2. Добавьте новую пару ключ-значение:

```json
{
  "mySection": {
    "myKey": "My translation"
  }
}
```

3. Используйте в компоненте:

```tsx
const { t } = useLanguage();
const text = t('mySection.myKey');
```

✅ **Все тексты переведены**

✅ **Готовые компоненты**

- Все компоненты уже интегрированы в page.tsx


## Добавление нового языка

Если нужно добавить новый язык (например, испанский):

1. Создайте папку: `app/i18n/locales/es/`
2. Создайте файл: `app/i18n/locales/es/main.json` с переводами
3. Обновите `app/i18n/config.ts`:

```ts
export const languages = {
  ru: 'Русский',
  en: 'English',
  kg: 'Кыргызча',
  es: 'Español',  // Добавьте новый язык
} as const;
```

4. Переводы автоматически станут доступны!
