# ⚡ Быстрый старт - Система аутентификации AVATAR

## 🚀 За 5 минут

### 1. Запустить приложение
```bash
npm run dev
```

**Результат**: Сервер запустится на http://localhost:3000

### 2. Открыть в браузере
```
http://localhost:3000
```

### 3. Нажать кнопку "Вход" в Header

### 4. Выбрать "Регистрация" и заполнить форму
```
Имя: Иван Петров
Email: test@example.com
Пароль: password123
Подтвердить: password123
```

### 5. Нажать \"Создать аккаунт\"

✅ **Готово!** Вы зарегистрированы и залогинены!

## 🎯 Что вы получили

- ✅ Красивое модальное окно входа/регистрации
- ✅ Google OAuth интеграция
- ✅ Защищенные пароли (bcryptjs)
- ✅ JWT токены (7 дней)
- ✅ Профиль в Header
- ✅ Мобильная версия
- ✅ Полная валидация

## 🌐 Google OAuth

Уже настроено! Используются твои ключи:
- `NEXT_PUBLIC_GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`

Просто нажми \"Войти через Google\" и он работает!

## 💾 БД и модели

Используется твоя Prisma схема:
- `User` - пользователь
- `UserProfile` - профиль
- `UserSession` - сессии
- `Customer` - информация клиента

Все автоматически создается при регистрации!

## 🆘 Если что-то не работает

1. **Проверить консоль браузера** (F12)
2. **Проверить логи сервера** (`npm run dev`)
3. **Перезагрузить страницу** (Ctrl+F5)
4. **Проверить .env** переменные
5. **Пересобрать проект** (`npm run build`)
