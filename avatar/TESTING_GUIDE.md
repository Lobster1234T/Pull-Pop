# 🧪 Руководство по тестированию системы аутентификации

## 🌐 Доступ к приложению

**URL**: http://localhost:3000 (или http://localhost:3001 если 3000 занят)

## 📝 Тестовые сценарии

### 1️⃣ Регистрация нового пользователя

1. Нажать кнопку **"Вход"** в Header
2. Выбрать вкладку **"Регистрация"**
3. Заполнить форму:
   - **Полное имя**: Иван Петров
   - **Email**: test@example.com
   - **Пароль**: password123
   - **Подтвердить пароль**: password123
4. Нажать **"Создать аккаунт"**
5. ✅ Ожидаемый результат: Страница перезагружается, в Header видно имя пользователя

### 2️⃣ Вход существующего пользователя

1. Нажать кнопку **"Вход"** в Header
2. Убедиться что выбрана вкладка **"Вход"**
3. Заполнить форму:
   - **Email**: test@example.com
   - **Пароль**: password123
4. Нажать **"Войти"**
5. ✅ Ожидаемый результат: Страница перезагружается, в Header видно имя пользователя

### 3️⃣ Тестирование валидации

#### Пустые поля
- Нажать "Войти" без заполнения полей
- ✅ Должно появиться сообщение об ошибке

#### Короткий пароль (регистрация)
- При регистрации ввести пароль менее 6 символов
- ✅ Должно появиться сообщение "Пароль должен быть не менее 6 символов"

#### Несовпадающие пароли
- При регистрации ввести разные пароли в поля
- ✅ Должно появиться сообщение "Пароли не совпадают"

#### Неверные учетные данные
- Попытаться войти с неправильным паролем
- ✅ Должно появиться сообщение "Invalid email or password"

### 4️⃣ Меню профиля

1. После входа в Header видно **ваше имя** вместо кнопки "Вход"
2. Нажать на имя пользователя
3. Откроется меню с:
   - Вашим именем
   - Вашим email
   - Кнопкой **"Выход"**
4. Нажать **"Выход"**
5. ✅ Ожидаемый результат: Страница перезагружается, видна кнопка "Вход"

### 5️⃣ Google OAuth

1. Нажать кнопку **"Вход"** в Header
2. Нажать **"Войти через Google"**
3. Откроется окно Google для входа
4. Войти с вашим Google аккаунтом
5. ✅ Ожидаемый результат: Редирект на /auth/callback → перезагрузка → вы залогинены

### 6️⃣ Мобильное меню

#### На мобильном размере (< 1024px):
1. В Header видна кнопка **Menu** (три полоски)
2. Нажать на неё
3. Откроется мобильное меню с:
   - Ссылками на разделы
   - Переключателем языка
   - Кнопкой входа/выхода
4. Нажать на пункт меню
5. ✅ Меню закрывается, переходите на нужный раздел

### 7️⃣ Переключение языков

1. В Header нажать на **"EN"** или **"RU"**
2. Откроется выпадающее меню с языками
3. Выбрать другой язык
4. ✅ Интерфейс обновляется, текст меняется

## 🔍 Проверка консоли браузера

### Открыть DevTools
- Нажать **F12** или **Ctrl+Shift+I**

### Network вкладка
- При регистрации/входе должны быть запросы:
  - `POST /api/auth/register` или `POST /api/auth/login`
  - Ответ: `200` с токеном и данными пользователя

### Console вкладка
- Не должно быть ошибок (красных сообщений)
- Может быть предупреждение о package-lock.json (это нормально)

### Application вкладка
- **Local Storage** должен содержать:
  - `authToken` - JWT токен
  - `user` - JSON объект с данными пользователя

## 🐛 Возможные проблемы и решения

### Проблема: Кнопка входа не работает
- **Решение**: Проверьте что модальное окно открылось (нажмите на серый фон чтобы закрыть и открыть снова)

### Проблема: Ошибка "User with this email already exists"
- **Решение**: Используйте другой email, это пользователь уже зарегистрирован

### Проблема: Google OAuth не работает
- **Решение**: Убедитесь что в .env установлены правильные GOOGLE_CLIENT_ID и GOOGLE_CLIENT_SECRET

### Проблема: Сервер не запускается
- **Решение**: Запустите `npm run build` и проверьте нет ли ошибок

### Проблема: После входа остаетесь на той же странице
- **Решение**: Это нормально, просто обновите страницу (F5), вы будете залогинены
