## 🎯 Как это работает

### Процесс бронирования с оплатой:

```
1. Пользователь открывает страницу /booking
   ↓
2. Заполняет форму:
   - Выбирает дату
   - Выбирает время
   - Выбирает зону (STANDARD, VIP, PS5)
   - Выбирает продолжительность (1-24ч)
   - Выбирает количество игроков
   ↓
3. Нажимает кнопку "ПОДТВЕРДИТЬ И ОПЛАТИТЬ"
   ↓
4. Открывается модальное окно Finik Pay с данными бронирования
   ↓
5. Модальное окно показывает:
   - Сумма платежа: 5 сом
   - Данные бронирования (дата, время, зона, продолжительность, игроки)
   - Способ оплаты: QR-код Finik
   - Валюта: KGS
   ↓
6. Пользователь нажимает "Оплатить 5 сомов"
   ↓
7. Редирект на платежную страницу Finik
   ↓
8. Пользователь сканирует QR-код своей карточкой Finik
   ↓
9. Платеж проходит
   ↓
10. Webhook обновляет статус бронирования в БД
   ↓
11. Пользователь видит успешное подтверждение
   ↓
12. Форма очищается для нового бронирования
```

1. **Открывает страницу бронирования:**
   ```
   http://localhost:3000/booking
   ```

2. **Заполняет форму:**

   - Платеж проходит

5. **Получает подтверждение:**
   - Видит сообщение об успехе
   - Получает письмо на почту
