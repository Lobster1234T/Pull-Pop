## 🎨 Дизайн и стиль

### Современный Glass-морфизм дизайн
- Полупрозрачные карточки (glass effect)
- Градиентные фоны (cyan → blue, orange → red и т.д.)
- Smooth transitions (300ms)
- Hover эффекты на всех элементах
- Плавные анимации (animations: float, glow, pulse, scale)

### Цветовая схема
- Основной: Cyan (#00d9ff) + Blue (#0284c7)
- Акценты: Orange (#ff6b35), Green (#00d97e)
- Фон: Dark blue gradient (#0a0e27 → #0f1a3a)
- Light theme: White background с dark text

### Типография
- Geist Sans для основного текста
- Font weights: 400, 600, 700, 900 (bold)
- Responsive sizes (text-sm → text-4xl)
- Line-height: 1.2 - 1.5 для читаемости

### Иконография
- Lucide React иконы
- Emoji для визуального интереса
- Цветные иконки в градиентных контейнерах
- 16x16 до 64x64 разные размеры

## 🔧 Технические особенности

### Frontend Stack
- **Framework:** Next.js 16.4.0
- **Styling:** Tailwind CSS 4
- **UI Library:** Lucide React 1.57.0
- **Runtime:** React 19.3.0
- **Language:** TypeScript

### Оптимизация
- Next.js Image Component для оптимизации изображений
- CSS Grid + Flexbox для layout
- Tailwind CSS для стилей
- Client Components для интерактивности
- Server Components для production builds

### Performance
- Build time: ~3-4 секунды
- Optimized images: JPEG, WebP
- Code splitting: автоматический
- Tree shaking: включён по умолчанию

### Responsive Design
- Mobile-first approach
- Breakpoints: sm (640px), md (768px), lg (1024px), xl (1280px)
- CSS Grid Media Queries
- Flexbox для адаптивности
- Viewport optimization
